# Project Overview

## Purpose

Provide a cute React icon component library (491 icons).

## Current State

- Package name: lolicon
- Tech stack: React 18, TypeScript, Bun, tsdown
- Icon count: 491
- Showcase site: Vite-based (`showcase/`)
- Hosting: lolicon.ichi0g0y.io

## Directory Structure

- `.ai/`: AI common rules
- `.claude/`: Claude-specific commands
- `.context/`: Shared workspace between agents
- `docs/`: Guides and finalized documentation
- `showcase/`: Icon gallery site (Vite + React + Tailwind CSS)
- `original/`: Original icon design files (.ai, SVG)
- `scripts/`: Code generation scripts
- `src/`: Source code
  - `src/Icon.tsx`: Dynamic icon component
  - `src/glyphs.tsx`: Auto-generated — glyph data
  - `src/icons/`: Auto-generated — individual icon components (491 files)
  - `src/index.ts`: Auto-generated — barrel exports
- `showcase/app/datas/icons.ts`: Auto-generated — icon list for documentation

## Auto-Generated Code

The following files are auto-generated by `scripts/migrate.mjs`. **Do not edit directly.**

## Build & Publish

- Build: `bun run build` (tsdown + tsc)
- Format: `bun run format`
- Lint: `bun run lint`
- npm publish: public access
